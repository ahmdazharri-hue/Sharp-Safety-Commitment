SAFETY COMMITMENT TWIBBON GENERATOR

Files:
- index.html: website entry page
- style.css: appearance and responsive layout
- script.js: photo, commitment, signature and PNG generation
- twibbon.png: supplied campaign design

To publish on GitHub Pages:
1. Upload all four files to the repository root (not the containing folder).
2. Repository Settings > Pages.
3. Build and deployment: Deploy from a branch.
4. Branch: main; folder: /(root); Save.
5. Wait for GitHub Pages deployment.

Important:
This is a starter version. Preview the image layout and adjust coordinates in script.js if needed.
The generator works locally in the user's browser and does not upload the photo/signature.
